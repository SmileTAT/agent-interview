## v2.0 核心差异点

1. **追问链**：每道核心题附 3~5 层面试官递进追问，还原真实面试深度
2. **系统设计题 + 评分维度（rubric）**：教用户"答到什么程度算好"
3. **真实面经溯源**：题目标注脱敏来源（公司 · 岗位 · 时间）
4. **内容保鲜机制**：题级 `last_reviewed_at` + 月度巡检，跟进 MCP/A2A/框架演进
