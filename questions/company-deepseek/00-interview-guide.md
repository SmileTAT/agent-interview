# DeepSeek 面试导读：流程、风格与备考建议（2026 扩招版）

> 本页为专题导读，不是题目。内容整理自公开面经与媒体报道（来源见文末），最后核对时间 2026-07。

## 招聘背景

- 2026 年 6 月 25 日，DeepSeek 宣布大规模招聘，目标**所有部门扩编至少一倍**：覆盖全栈开发/算法、AI 核心系统研发、深度学习研究员、模型数据策略、产品、运营等 7 大类 33 个岗位，工作地北京/杭州，全部岗位开放实习申请；
- 新设 **Agent Harness 团队**（代码 AI Agent 产品方向），流程为 1 轮笔试 + 3 轮面试；
- 特设"AI 跨学科人才"岗位，不限专业背景；研究岗以博士优先，顶尖硕士/本科可投实习。

## 面试流程与风格（来自公开面经的一致性报告）

| 特征 | 说明 |
|------|------|
| **代码即正义** | 有面经报告 70 分钟面试中自我介绍仅 30~40 秒，随即持续深挖简历项目与代码细节；通常有两轮编程面 |
| **按简历定制编程题** | 多篇面经提到编程题根据候选人专业背景定制，而非统一题库——压制"背模板"的噪音 |
| **高强度追问** | 有应届博士候选人报告被连续追问约 3 小时的"压力面" |
| **轮次结构** | 常见为：一面基础与项目 → 二面深入模型技术（MLA/MoE/GRPO 等，约 90 分钟）→ 三面系统与分布式训练设计（约 90 分钟）|

## 高频考察方向（本专题题目的选题依据）

1. MLA 原理与 KV Cache 压缩（几乎必问）
2. GRPO 与 PPO/DPO 的对比，二面可能要求手写公式
3. R1 / R1-Zero / V3 的关系与 R1 多阶段训练流程（冷启动、奖励设计、蒸馏）
4. DeepSeekMoE 架构、通信开销与负载均衡
5. 手写 Multi-Head Attention 及其变体讨论
6. 长上下文扩展（YaRN）、分布式训练与训练成本估算
7. 结合候选人自身项目的 LoRA 微调、RAG 优化、幻觉治理等应用问题

## 备考建议

- **精读两份技术报告**：DeepSeek-V3 Technical Report 与 DeepSeek-R1 论文——二面直接按报告内容追问的报告很多；
- **自己的项目准备到代码级**："每一行都可能被问"，重点准备设计取舍与失败教训；
- **公式层面掌握 GRPO/DPO**：能写出目标函数并解释每一项，而不只是概念对比；
- 关注其 Agent 方向新动向（Agent Harness 团队）——Agent 工程能力（本题库前十个主题）正在成为其考察面的一部分。
