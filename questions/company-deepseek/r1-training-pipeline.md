# 讲一讲 DeepSeek-R1 的完整训练流程：R1-Zero、冷启动与四阶段

<QuestionMeta />

## 题目

面经报告二面常要求按技术报告完整走一遍：R1-Zero 是什么、为什么需要冷启动、R1 的多阶段训练各做什么、蒸馏版本怎么来的。

::: details 参考答案

**起点：R1-Zero——验证"纯 RL 能否激发推理"**
在 DeepSeek-V3 Base 上**跳过 SFT 直接做大规模 RL**（GRPO + 规则奖励：准确性 + 格式）。结果：推理能力随训练"自我进化"——思维链自发变长、出现自我验证与反思（"aha moment"）、数学基准大幅提升。但产物不适合直接用：思维链**可读性差、中英文混杂**。R1-Zero 的意义是科学验证：推理能力可以不靠人类示范、由可验证奖励的 RL 激发。

**R1 的四阶段流水线（解决"能推理但不好用"）**：

1. **冷启动 SFT**：收集数千条高质量长思维链数据（含人工修整的 R1-Zero 输出），带可读性设计（固定输出模式、末尾摘要），对 V3-Base 做 SFT——给 RL 一个格式良好、可读的起点，也显著加速收敛；
2. **面向推理的 RL**：对冷启动模型做 GRPO（同 R1-Zero 的规则奖励），并加入**语言一致性奖励**治理语言混杂——牺牲少许基准分换可读性；
3. **拒绝采样 + 全领域 SFT**：用阶段 2 的模型采样，**只保留答案正确、过程合格的轨迹**（拒绝采样）得到约 60 万推理样本，再混合约 20 万非推理数据（写作、问答、翻译，部分复用 V3 的 SFT 数据管线），对 V3-Base 重新 SFT——把推理能力与通用能力装进同一个模型；
4. **全场景 RL**：再做一轮 RL——推理数据继续规则奖励，通用数据用奖励模型对齐人类偏好（有用性/无害性），得到最终 R1。

**蒸馏版本**：用阶段 3 的约 80 万样本对 Qwen/Llama 系列小模型做**纯 SFT**（不做 RL），推理能力大幅迁移——论文的结论是：对小模型，**蒸馏大模型的推理模式比直接对小模型做 RL 更有效且更省**。

**答题关键**：R1-Zero 的科学意义与缺陷 → 冷启动解决什么 → 四阶段各自的目标与数据构成 → 蒸馏结论。能说出"每一阶段是在修上一阶段的什么问题"才算真懂。

:::

## 追问链

::: details 追问 1（面经真实追问方向）：冷启动数据的构成和设计细节是什么？为什么几千条就够？

构成：以长思维链示范为主，来源包括少样本提示引导生成、R1-Zero 输出的人工筛选与改写，统一成可读模板（推理过程 + 末尾摘要的固定结构）。几千条就够的原因：冷启动的目标**不是教会推理**（那是 RL 阶段的事），只是校准输出格式与可读性、给 RL 一个更好的初始分布——格式类行为是小数据就能塑形的；推理能力本身来自随后的大规模 RL 探索。这一问考察对"SFT 教格式、RL 长能力"分工的理解。

:::

::: details 追问 2：为什么阶段 3 要回到 V3-Base 重新 SFT，而不是在阶段 2 的模型上继续训？

阶段 2 的模型是"推理特化"的——长期只在推理任务上做 RL，通用能力与输出分布已经偏斜。回到干净的 V3-Base，用"高质量推理样本 + 通用样本"的**混合配方一次性 SFT**，能同时获得推理与通用能力且互相不打架，比在偏科模型上"补课"更可控。这体现了后训练的一个实用原则：与其修一个跑偏的模型，不如带着更好的数据回到干净起点。

:::

::: details 追问 3：蒸馏版（如 R1-Distill-Qwen-32B）和对小模型直接做 RL 相比，为什么前者更好？这个结论的边界在哪？

论文的对照实验：对 Qwen-32B 直接做大规模 RL，效果显著不如用 R1 的 80 万样本蒸馏。解释：RL 只能强化基模型**已有分布内**的行为，小模型自身难以采样出高质量长推理轨迹，RL 无米下锅；蒸馏则直接注入大模型已经探索出的推理模式。边界：蒸馏的上限受教师能力与数据覆盖限制，蒸馏后再叠加 RL 仍可能有增益（论文亦提及）；且"能力密度"随模型规模仍有天花板——小模型装得下模式，装不下全部深度。

:::
