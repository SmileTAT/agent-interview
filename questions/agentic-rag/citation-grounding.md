# RAG 系统怎么抑制幻觉并生成可靠的引用？

<QuestionMeta />

## 题目

RAG 本身是抑制幻觉的手段，但"检索了仍然幻觉"和"引用了错误来源"依然常见。请给出系统性的 grounding 方案。

::: details 参考答案

先分清 RAG 幻觉的三种形态，对策不同：

**1. 检索失败型**（没检到相关内容，模型拿参数知识硬答）
→ 治本在检索层（召回优化），但生成层要有**安全阀**：明确指示"检索内容不足以回答时，说明查不到，禁止用自身知识补全"；对检索结果做相关性门槛，低于阈值直接走"无法回答"路径而不是把垃圾塞给模型。

**2. 综合失真型**（检到了，但模型概括时添油加醋/张冠李戴）
→ 生成约束：要求**逐句可溯源**——回答中的每个事实性陈述标注来源块编号（结构化引用格式）；提示中强调"只使用提供的材料，区分材料观点与你的补充说明"。

**3. 引用错配型**（答案对，引用的来源却不支持该论述）
→ 这最伤信任：用户点开引用发现对不上。对策见下面的校验层。

**校验层（生成后验证）**：

- **忠实性检查**：用一个校验模型（或 NLI 模型）逐条判断"该陈述是否被所引块支持"，不支持的触发重写或降级为"据推测"；
- 高风险场景（医疗/法务/金融）把校验做成硬门禁，不过就不出答案。

**产品层兜底**：引用可点击、显示原文片段——让用户能快速核验本身就是幻觉的威慑与止损；对低置信度回答显式标注。

**答题关键**：三种幻觉形态分治 + "无法回答"是合法输出 + 生成后校验层 + 可核验的引用产品设计。

:::

## 追问链

::: details 追问 1："逐句引用"会不会让回答变得破碎难读？

会有张力，平衡手段：引用粒度放宽到"段落级/论点级"而不是逐句（一段综述挂 2~3 个来源）；引用渲染放脚注/侧栏，正文保持流畅；区分内容类型——事实性陈述（数字、日期、结论）必须挂引用，衔接性文字不用。核心是"**可核验性**"而不是"引用密度"：用户对任何一个关键论断都能一键找到出处，就达标了。

:::

::: details 追问 2：忠实性校验模型自己也可能错，这层到底值不值得加？

用数据说话：校验层的价值 = 拦截的真幻觉（true positive）带来的风险减免 − 误拦（false positive）造成的可用性损失 − 延迟成本。实践中 NLI 式校验对"明显不支持"的检出率不错，作为**分流器**很划算：高置信支持的直接放行，明显不支持的拦截，中间地带标注"低置信"放行——不追求二元判断，追求风险分层。校验层自身也要有评测集（标注好的支持/不支持对）持续监控。

:::

::: details 追问 3：检索内容之间互相矛盾时，grounded 的回答应该长什么样？

正确形态是**呈现分歧而不是伪造共识**："文档 A（2024 版手册）称 X，文档 B（2026 更新公告）称 Y"，并按元数据给出倾向（更新时间、来源权威级）。工程上：提示中明确矛盾处理规则；索引层给文档带时效与权威元数据供裁决；产品上允许"带条件的回答"。最危险的输出是模型静默混合两个矛盾来源，生成一个两边都不支持、但看起来自洽的答案——这是忠实性校验要重点抓的模式。

:::
