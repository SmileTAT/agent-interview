## 三、产品概述

### 3.1 需求背景

随着大模型技术的爆发式发展，**模型厂商**（DeepSeek、MiniMax、智谱等）和**国内外科技大厂**（百度、阿里、腾讯、字节跳动、华为、OpenAI、Google、Anthropic、Microsoft等）对AI算法人才的需求激增。2026年春招，字节、腾讯、百度、华为、美团、拼多多、快手、微软、OpenAI、智谱AI等大厂/AI公司已全面加入AI Coding和大模型知识考察。

然而，当前市面上的面试题库主要覆盖传统算法题和通用八股文，**缺乏系统化整理各厂商模型架构原理、技术迭代历程、核心技术差异**的垂直题库。面试官考察的已不仅是"背概念、记公式"，而是对候选人底层认知的扎实度、工程落地的实战能力、问题解决的闭环思维、行业前瞻的认知高度的全维度考察。

### 3.2 产品定位

**"专注AI大模型全栈技术的面试题库"**

覆盖**模型厂商专项**（DeepSeek/MiniMax/智谱）与**大厂AI岗通用**（百度/阿里/腾讯/字节/华为/OpenAI/Google/Anthropic等）两大维度，面向准备求职AI算法、大模型研发、推理优化、AI应用落地等岗位的候选人。

### 3.3 目标用户

| 用户类型 | 描述 |
|---------|------|
| **求职者（核心用户）** | 准备面试模型厂商（DeepSeek/MiniMax/智谱）或国内外科技大厂AI岗位的算法工程师、AI研发人员 |
| **面试官（次要用户）** | 需要出题的面试官，可参考题库设计面试问题 |
| **内容贡献者（社区用户）** | 愿意分享面经、补充题目的行业从业者 |

### 3.4 核心价值

- **全行业覆盖**：从模型厂商到互联网大厂，覆盖AI大模型全产业链
- **垂直领域精准**：深度聚焦模型架构、注意力机制变体、强化学习算法、推理优化等核心技术
- **体系化整理**：按厂商/技术主题/岗位方向三维组织
- **紧跟前沿**：覆盖各厂商最新模型迭代（文心5.0、Qwen3-Max、混元2.0、UltraMem、GPT-5、Gemini 3、Claude 4等）


## 四、用户故事

- **作为** 准备面试大模型岗位的求职者，**我希望** 按厂商和主题浏览面试题，**以便** 高效复习特定方向的知识点。
- **作为** 求职者，**我希望** 查看每道题的详细解析和参考答案，**以便** 理解背后的原理而非死记硬背。
- **作为** 用户，**我希望** 通过搜索快速找到我关心的技术点（如"MLA""线性注意力""UltraMem"），**以便** 针对性查漏补缺。
- **作为** 面试官，**我希望** 按难度和技术主题筛选题目，**以便** 快速组卷。
- **作为** 内容贡献者，**我希望** 能提交新的面试题或补充解析，**以便** 帮助社区完善题库。


## 五、MVP功能范围

### 5.1 MVP核心原则

严格遵循 **YAGNI原则**（You Aren't Gonna Need It），MVP只包含验证产品核心价值的最小功能集。**核心价值 = 让用户找到并学习AI大模型面试题**。

### 5.2 MVP功能清单

#### P0（必须有，MVP必做）

| 功能模块 | 功能点 | 优先级 | 说明 |
|---------|--------|--------|------|
| **题目浏览** | 按厂商分类浏览 | P0 | 模型厂商（DeepSeek/MiniMax/智谱）+ 国内大厂（百度/阿里/腾讯/字节/华为）+ 海外大厂（OpenAI/Google/Anthropic/Microsoft）+ 通用基础 |
| | 按技术主题筛选 | P0 | MoE / 注意力机制 / 强化学习 / 推理优化 / 多模态 / Agent / RAG 等标签 |
| | 按岗位方向筛选 | P0 | 预训练/对齐 / 推理优化/工程 / 应用落地/解决方案 / 多模态 |
| | 题目列表展示 | P0 | 展示题目标题、难度、分类标签、所属厂商 |
| **题目详情** | 查看题目内容 | P0 | 完整题目描述 |
| | 查看参考答案 | P0 | 带解析的参考答案 |
| | 展开/折叠答案 | P0 | 保护用户先思考再查看 |
| **搜索** | 全文关键词搜索 | P0 | 支持技术术语搜索（如"MLA""GRPO""UltraMem"） |
| **内容管理** | 管理员后台录入题目 | P0 | 支持CRUD操作 |

#### P1（重要，MVP后可快速迭代）

| 功能模块 | 功能点 | 优先级 | 说明 |
|---------|--------|--------|------|
| **用户系统** | 注册/登录 | P1 | 基础账号体系 |
| | 收藏题目 | P1 | 个人收藏夹 |
| | 刷题进度记录 | P1 | 记录已看/未看 |
| **题目组织** | 按难度分级 | P1 | 初级/中级/高级 |
| | 厂商对比专题 | P1 | 多厂商横向对比（如MoE架构对比） |

#### P2（暂不纳入MVP）

- 在线代码编辑器 / 代码执行
- AI生成题目
- 模拟面试功能
- 社区讨论/评论
- 移动端App

### 5.3 MVP排除项（明确不做）

| 排除项 | 原因 |
|--------|------|
| 在线编程环境 | 本题库聚焦"知识型"面试题，非算法编程题 |
| 社交/社区功能 | 增加复杂度，偏离核心价值 |
| 视频/音频内容 | 内容制作成本高，初期不适合 |
| 多语言支持 | 初期仅支持中文 |


## 六、信息架构

### 6.1 页面结构

```
├── 首页
│   ├── 导航栏（分类入口 + 搜索框）
│   └── 题目列表（默认展示全部，可筛选）

│   ├── 通用基础（Transformer、预训练、RLHF、微调方法等）
│   ├── 模型厂商专题
│   │   ├── DeepSeek（MoE、MLA、GRPO、FP8训练等）
│   │   ├── MiniMax（线性注意力、MSA、CISPO、混合架构等）
│   │   └── 智谱 GLM（GLM架构、DSA、Agentic Engineering等）
│   ├── 国内大厂专题
│   │   ├── 百度文心（原生全模态、超稀疏MoE、飞桨等）
│   │   ├── 阿里通义（Qwen3-Max、Qwen3-Next、MoE等）
│   │   ├── 腾讯混元（HY 2.0、MoE、RLVR+RLHF等）
│   │   ├── 字节豆包（UltraMem、稀疏架构、MoE等）
│   │   └── 华为盘古（π新架构、MoGE、昇腾适配等）
│   └── 海外大厂专题
│       ├── OpenAI（GPT系列演进、MoE、推理模型等）
│       ├── Google DeepMind（Gemini、稀疏MoE、原生多模态等）
│       ├── Anthropic（Claude、混合推理架构等）
│       └── Microsoft（Phi系列、MAI、Azure AI等）
├── 题目详情页
│   ├── 题目内容
│   ├── 标签/难度/所属厂商
│   └── 参考答案（默认折叠）
├── 搜索页
│   └── 搜索结果列表
└── 管理后台
    ├── 题目管理（增删改查）
    └── 分类/标签管理
```

### 6.2 核心数据模型

**题目表（Question）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| title | VARCHAR(200) | 题目标题 |
| content | TEXT | 题目内容（支持Markdown） |
| answer | TEXT | 参考答案（支持Markdown） |
| category | VARCHAR(50) | 所属分类（通用/模型厂商/国内大厂/海外大厂） |
| vendor | VARCHAR(50) | 所属具体厂商（如"DeepSeek""百度""OpenAI"） |
| tags | JSON | 技术标签数组（如["MoE","MLA"]） |
| difficulty | ENUM | 初级/中级/高级 |
|岗位方向 | ENUM | 预训练对齐/推理优化/应用落地/多模态 |
| view_count | INT | 浏览次数 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |


## 七、各厂商核心技术要点（题库内容框架）

### 7.1 模型厂商

| 厂商 | 核心模型 | 关键技术 | 面试考点 |
|------|---------|---------|---------|
| **DeepSeek** | V3 / R1 | DeepSeekMoE、MLA、GRPO、FP8混合精度 | MoE架构原理、KV Cache压缩、强化学习算法 |
| **MiniMax** | 01系列 / M1 / M3 | 线性注意力、MSA、CISPO、7:1混合架构 | 线性注意力复杂度、稀疏注意力机制 |
| **智谱** | GLM-4.5 / GLM-5 | MoE、DSA、Agentic Engineering | GLM架构演进、稀疏注意力、智能体工程 |

### 7.2 国内大厂

| 厂商 | 核心模型 | 关键技术 | 面试考点 |
|------|---------|---------|---------|
| **百度** | 文心5.0（2.4万亿参数） | 原生全模态统一建模、超稀疏MoE（激活参数<3%）、飞桨框架、思维链+行动链强化学习 | 原生全模态 vs 后期融合、超稀疏MoE效率 |
| **阿里** | Qwen3-Max（万亿参数）、Qwen3-Next（80B/激活3B） | MoE架构、混合注意力、MTP多token预测 | MoE参数效率、训练成本优化、Agent能力 |
| **腾讯** | 混元HY 2.0（406B/激活32B） | MoE架构、256K上下文、RLVR+RLHF双阶段强化学习 | MoE推理效率、强化学习策略、长上下文 |
| **字节** | 豆包1.5 Pro | UltraMem稀疏架构（推理速度提升2-6倍，成本降低83%）、MoE | UltraMem vs MoE、推理优化、访存瓶颈 |
| **华为** | 盘古5.0 | π新架构（昇腾亲和Transformer）、MoGE分组专家混合、"5+N+X"三层架构 | 昇腾适配、模型压缩、行业大模型 |

### 7.3 海外大厂

| 厂商 | 核心模型 | 关键技术 | 面试考点 |
|------|---------|---------|---------|
| **OpenAI** | GPT-5（2025.8） | 统一多模型系统（基础模型+深度推理模块+实时路由）、MoE架构（gpt-oss-120b: 1170B/激活51B） | GPT架构演进、推理模型、模型路由 |
| **Google** | Gemini 3 Pro（2025.11） | 稀疏MoE Transformer、原生多模态、1M上下文、TPU训练 | 稀疏MoE、原生多模态、TPU集群训练 |
| **Anthropic** | Claude 3.7/4系列 | 混合推理架构（快速应答+深度思考整合至单一模型）、20万tokens上下文 | 混合推理架构、速度与精度权衡 |
| **Microsoft** | Phi-4（38亿参数）、MAI系列 | 解码器Transformer、128K上下文、模型路由器 | 小型语言模型SLM、模型路由、Azure AI平台 |

### 7.4 通用基础模块（跨厂商共通）

- Transformer架构（自注意力、多头注意力、位置编码、FFN）
- 预训练 vs 微调 vs 强化学习（RLHF/DPO/GRPO/CISPO）
- MoE架构原理与演进
- 注意力机制变体（MHA/GQA/MQA/MLA/线性注意力/稀疏注意力）
- 微调方法（Full Fine-tuning、LoRA、QLoRA、Prefix Tuning、P-Tuning）
- RAG系统核心组件与优化方向
- 推理优化（量化、KV Cache、批处理、模型压缩）
- 模型评估与监控（离线指标、在线指标、数据漂移）


## 八、业务流程

### 8.1 用户刷题流程

```
用户进入首页 → 选择分类/厂商/搜索关键词 → 浏览题目列表 →
点击进入题目详情 → 阅读题目 → 点击展开答案 →
（可选）收藏题目 / 标记已学
```

### 8.2 管理员录入题目流程

```
管理员登录后台 → 点击"新增题目" →
填写题目、答案、所属厂商、分类、标签、难度、岗位方向 →
提交 → 前台立即可见
```


## 九、非功能需求

| 维度 | 要求 |
|------|------|
| **性能** | 页面加载时间 < 2秒；搜索响应 < 1秒 |
