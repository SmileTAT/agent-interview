> 审核对象：《模型厂商面试题库 —— MVP版本产品需求文档（PRD）v1.1》
> 审核日期：2026-07-13
> 审核结论：**不建议按 v1.1 直接开发**。定位与目标（AI Agent 方向面试题集）错位，且存在事实性错误与差异化不成立的问题。已重写为 v2.0（见 `docs/prd-ai-agent-question-bank-v2.0.md`）。

## 二、关键问题清单

### 问题 1：定位漂移，与真实目标错位（最严重）

- v1.1 的主体内容（第七章 60% 篇幅）是各厂商**模型架构**知识点：MLA、UltraMem、MoGE、超稀疏 MoE……这是「模型底层原理八股」，对应的岗位是预训练/推理优化。
- 而目标是 **AI Agent 方向**：2026 年 Agent 岗面试考察的是规划与推理模式（ReAct / Plan-and-Execute / Reflection）、工具调用与 MCP、上下文工程、记忆系统、多智能体协作、Agentic RAG、轨迹级评测、生产级系统设计——这些在 v1.1 中只以两个标签（"Agent""RAG"）一带而过。
- **结论：不是"优化"问题，而是需要重定位。**

### 问题 2：按"厂商"组织内容，维护成本高且易过时

- 厂商维度是新闻式知识：GPT-5、Gemini 3 Pro、Claude 4 这类版本号以季度为单位过期，题库会持续背负"内容腐烂"债务。
- Agent 面试官几乎不考"某厂商模型参数量"，考的是可迁移的工程能力。
- 建议：**主维度改为"能力主题 × 题目类型 × 难度"**，厂商/框架降级为标签。

### 问题 3：事实性错误（内容型产品的致命伤）

术语表（12.2）至少有以下错误：

| PRD 原文 | 问题 |
|---------|------|
| "CISPO：智谱自研强化学习算法" | CISPO 是 **MiniMax** 在 M1 中提出的（PRD 自己的 7.1 表格也写在 MiniMax 行，前后矛盾） |
| "DSA：DeepSeek Sparse Attention（智谱）" | DSA 是 **DeepSeek** V3.2 的稀疏注意力，归到智谱名下错误 |
| "Claude 3.7/4系列" | 截至 2026 年已过时（Claude 5 家族已发布），印证问题 2 的"内容腐烂"风险 |
| 数据模型字段"岗位方向" | 混用中文字段名，工程上不可用 |

- 建议：新版 PRD 必须加入**内容审校与保鲜机制**（双人审校、来源标注、时效复查字段）。

### 问题 4：竞品分析过浅，差异化不成立

v1.1 只列了 3 个竞品且判断已过时。2026 年实际竞争格局（详见 v2.0 第四章）：

- **小林面试笔记 / 卡码笔记 / JavaGuide AI 版**：已系统覆盖 Agent、RAG、MCP、Context Engineering，含大量图解与答案解析，且月度更新——v1.1 声称的"竞品不聚焦 AI 大模型垂直领域"已经不成立。
- **海外**：DataCamp、Interview Coder、igmGuru、Udemy 等已有成规模的 Agentic AI 面试题合集；GitHub 上有 AgentGuide 等开源题库。
- **结论：「做一个 Agent 垂直题库」本身已不是差异点，必须在题目形态与内容机制上差异化**（见 v2.0 的四大差异点：追问链、系统设计题+评分维度、真实面经溯源、月度保鲜）。

### 问题 5：MVP 的 P0 仍然偏重

- "管理员后台 CRUD" 对验证核心价值非必需：MVP 阶段用 **Git + Markdown + 静态站生成** 即可完成录入、审校（PR review 即审校流）、发布，开发量减少约 1/3，还天然获得版本历史与协作贡献能力。
- 后台系统降到 P1，等内容量和贡献者规模验证后再建。

### 问题 6：指标与内容生产计划不闭环

- "Week 1 整理 150+ 道题"没有生产流程支撑，速度与质量必然冲突；且缺北极星指标。
- DAU ≥ 50 没有任何渠道/冷启动策略支撑。
- 建议：定义北极星指标（周有效学习用户），补内容生产 SOP 与冷启动渠道（见 v2.0 第十、十一章）。

### 问题 7：缺"题目类型"维度

- Agent 岗面试的主力题型是**系统设计题**（如"设计企业级智能客服 Agent"）、**场景排错题**（工具调用死循环、上下文溢出）、**追问链**（3~5 层递进追问），v1.1 的数据模型只支持单问单答的知识题。

## 三、v1.1 中值得保留的部分

- YAGNI 原则声明与 P0/P1/P2 分层方法（v2.0 沿用）。
- "展开/折叠答案"的学习保护设计。
- 通用基础模块（7.4）中与 Agent 相关的条目（RAG、推理优化、RLHF/DPO/GRPO）作为"交叉基础"保留。
- 非功能需求与阶段划分框架。

## 四、处理方式

- v1.1 归档，不再迭代。
- 新版见 **`docs/prd-ai-agent-question-bank-v2.0.md`**：重定位为「AI Agent 工程面试题库」，重写信息架构、数据模型、内容框架、竞品差异与增长指标。
